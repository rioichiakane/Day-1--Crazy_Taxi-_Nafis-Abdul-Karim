# Day-1--Crazy_Taxi-_Nafis-Abdul-Karim

repository adalah struktur penyimpanan data yang menyimpan seluruh berkas (file), direktori, dokumen, serta riwayat perubahan (commit history) dari suatu proyek pemrograman.

Tujuan dan Kegunaan Repository
- Pencatatan Riwayat (Version Control), yaitu menyimpan histori commit lengkap beserta nama pembuat dan pesan perubahannya.
- Percabangan (Branching), yaitu memungkinkan pembuatan fitur baru atau perbaikan bug di ruang terisolasi (branch) tanpa mengganggu kode utama (main/master).
- Penggabungan (Merging), yaitu menggabungkan kembali branch fitur yang selesai dibuat ke dalam branch utama.
- Kolaborasi Tim, untuk memudahkan peninjauan kode (code review), pull request, dan manajemen akses kontributor.
